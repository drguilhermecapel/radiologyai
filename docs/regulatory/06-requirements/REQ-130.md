# REQ-130 — TotalSegmentator roda em subprocesso, offline, sem telemetria e só com pesos verificados

## Requisito

O adaptador TotalSegmentator (`radiologyai.analysis.adapters.ct_totalseg`) DEVE executar o
modelo num processo filho cujo ambiente aponta todos os proxies HTTP(S) para uma porta fechada
(`127.0.0.1:9`) e cujo `config.json` do TotalSegmentator tem `send_usage_stats: false`
forçado antes da importação do pacote. O filho DEVE recusar rodar quando faltar qualquer pasta de
pesos esperada (nunca baixar). Os pesos expostos ao TotalSegmentator DEVEM ser somente os
arquivos verificados por sha256 pelo registro (árvore de *links* montada em `load`), e a versão
instalada do TotalSegmentator DEVE ser exatamente a fixada no manifesto. Os manifestos NÃO
DEVEM fixar hash digitado: o sha256 vem dos bytes reais (`pin`).

## Justificativa

Download silencioso troca o modelo avaliado por outro (H-04) e telemetria envia metadados de uso
do serviço para fora do host (LGPD). Um subprocesso sem rede transforma ambos em falha alta.
