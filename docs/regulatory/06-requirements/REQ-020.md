# REQ-020 — Integridade verificável dos pesos

## Requisito

Todo model card DEVE declarar `weights_sha256` como 64 caracteres hexadecimais
minúsculos. O sistema DEVE rejeitar, na carga, qualquer valor que não satisfaça esse
formato, e DEVE verificar o hash do arquivo antes de qualquer inferência.

## Justificativa

`models/model_registry.json` do v1 declarava hashes contendo 'g', 'h', 'i' — não
hexadecimais — para arquivos que nunca existiram.
