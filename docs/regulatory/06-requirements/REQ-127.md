# REQ-127 — Pesos de RX desserializados somente a partir dos bytes conferidos

## Requisito

Os adaptadores de RX DEVEM ler cada arquivo de pesos uma única vez, conferir o sha256 desses
bytes contra o manifesto e desserializar exatamente esses bytes (sem reabrir o caminho). A
desserialização completa (pickle) SÓ PODE ocorrer para peso declarado `unsafe_pickle: true`; os
demais DEVEM usar `weights_only`. A biblioteca de origem NÃO DEVE baixar pesos durante a carga.

## Justificativa

Trocar o arquivo entre a verificação e a carga, ou deixar a biblioteca baixar outro arquivo,
quebra a ligação entre resultado e pesos auditados; pickle não conferido executa código
arbitrário (RISK-004, RISK-020).
