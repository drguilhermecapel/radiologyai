# REQ-006 — Inverter MONOCHROME1

## Requisito

Quando `PhotometricInterpretation` for `MONOCHROME1`, o sistema DEVE inverter os valores
de pixel, preservando a faixa dinâmica.

## Justificativa

Sem inversão a imagem é processada em negativo. Um modelo treinado em MONOCHROME2 falha
de modo silencioso e catastrófico.
