# REQ-063 — O sistema nunca afirma normalidade

## Requisito

Nenhuma saída, texto de laudo ou resposta de API DEVE afirmar que um exame é normal.
Ausência de achado provável DEVE ser reportada como tal, com declaração explícita de que
não constitui afirmação de normalidade. Toda saída DEVE indicar que requer revisão
médica.

## Justificativa

Ausência de evidência de um achado não é evidência de ausência. Uma afirmação de
normalidade emitida por software não validado convida o viés de automação (perigo H-02).
