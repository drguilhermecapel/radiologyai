# REQ-170 — Modelo exploratório pedido explicitamente exige modo pesquisa

## Requisito

Pedir em `model_ids` um modelo de rota `research`, com `visibility_default: research` ou listado como pesquisa no roteamento (ou que dependa de um) DEVE exigir a permissão de modo pesquisa (403 caso contrário) e DEVE gravar a análise como de modo pesquisa.

## Justificativa

Sem isso, `model_ids` contornava o controle de acesso de `include_research`.
