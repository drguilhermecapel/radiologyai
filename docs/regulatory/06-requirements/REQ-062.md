# REQ-062 — Política de abstenção a partir de medição

## Requisito

A política de abstenção DEVE ser construída a partir de pontos de operação medidos em
artefatos de avaliação. Achados críticos DEVEM receber banda de indeterminação mais
larga. Rótulo sem medição válida DEVE ser classificado como não avaliável,
independentemente do escore.

## Justificativa

Limiares inventados não constituem política de risco. Para achado crítico o custo de um
falso negativo domina o de um falso positivo: na dúvida o sistema deve se abster, não
negar.
