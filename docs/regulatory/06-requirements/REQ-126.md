# REQ-126 — Zero-shot de RX somente no modo pesquisa e sem ponto de operação

## Requisito

Modelos zero-shot de RX (CheXzero) DEVEM ser declarados com `task: zero_shot`, roteamento e
visibilidade `research`, sem pontos de operação, e com `commercial_use: no` quando os pesos
derivarem de dados de acesso restrito. O escore DEVE reproduzir o método publicado (softmax do
par de prompts positivo/negativo) e NÃO DEVE ser apresentado como probabilidade de doença.

## Justificativa

Saída exploratória lida como validada é perigo identificado (RISK-012); pesos de dados com
termos restritivos exigem sinalização (RISK-014).
