# REQ-140 — Mamografia usa a VOI completa do DICOM (inclusive SIGMOID) ou é recusada

## Requisito

A conversão para 8 bits dos modelos de mamografia DEVE reproduzir a do código original
(`load_image_from_dicom` do `ianpan/mammoscreen`): VOI do arquivo aplicada pelo próprio
`pydicom` (`VOILUTSequence` preferida à janela; função `LINEAR`, `LINEAR_EXACT` ou
`SIGMOID` conforme `VOILUTFunction`), inversão MONOCHROME1 por `max - v` e min-max para
`uint8`. Um DICOM sem os parâmetros VOI completos (carregado sem
`radiologyai.modalities.mg.loader.load_mammogram`) NÃO DEVE ser convertido com uma janela
presumida: o portão do adaptador DEVE recusá-lo com motivo `unsupported_input`. Função VOI
desconhecida, imagem constante, imagem colorida e raster que não seja 8 bits DEVEM levantar
`UnsupportedInputError`.

## Justificativa

A CMMD declara `VOILUTFunction = SIGMOID`; uma janela linear no lugar da sigmoide muda a
entrada do modelo sem erro visível e o escore resultante parece legítimo (perigo H-05).
