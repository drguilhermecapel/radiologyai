# REQ-104 — Tipo de exame inferido de forma conservadora; desconhecido exige humano

## Requisito

A inferência do tipo de exame DEVE usar apenas metadados de aquisição e DEVE devolver
`UNKNOWN` quando modalidades se misturam, quando a descrição é ambígua ou ausente, ou
quando um clipe de ultrassom não se identifica como ecocardiograma. `analyze` NÃO DEVE
rodar com tipo `UNKNOWN`: DEVE levantar `ExamTypeUnknownError` para que um humano escolha.
Modelos só rodam em tipos de exame declarados no seu manifesto.

## Justificativa

Roteamento errado (RISK-017) aplica um modelo a uma população para a qual ele não foi
treinado e produz números plausíveis e sem sentido.
