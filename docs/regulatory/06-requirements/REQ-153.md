# REQ-153 — Des-identificação na ingestão e ausência de dado pessoal persistido

## Requisito

Todo DICOM DEVE ser des-identificado na ingestão com `radiologyai.io.deident` e a chave `MEDAI_DEIDENT_KEY` (pseudônimo HMAC estável); sem a chave a ingestão de DICOM DEVE ser recusada. PNG/JPEG DEVEM ser recodificados sem metadados e os campos de texto livre do cabeçalho NIfTI DEVEM ser apagados. Banco, repositório de artefatos, auditoria e logs NÃO DEVEM conter nome, ID original, data de nascimento ou instituição do paciente; a busca DICOMweb NÃO DEVE repassar identificadores. Possível texto gravado no pixel DEVE gerar aviso (a des-identificação não o remove).

## Justificativa

Dado de saúde é dado sensível (LGPD Art. 5 II). O legado pseudonimizava com `hash()` salgado por processo e cobria 7 tags (HONEST_STATUS.md §6). Texto gravado em pixel de US/eco continua sendo risco declarado (RISK-009).
