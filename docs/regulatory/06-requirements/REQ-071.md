# REQ-071 — Reconstrução completa da decisão

## Requisito

Todo registro DEVE conter hash da entrada, identificador do model card, sha256 dos
pesos, versão do código, modalidade, usuário e a decisão do médico. A trilha NÃO DEVE
armazenar dados de pixel nem identificadores diretos de paciente.

## Justificativa

É o que torna o médico-no-circuito verificável em vez de apenas declarado, sem
transformar a trilha em repositório de dado sensível.
