# REQ-002 — Nenhum número gerado aleatoriamente

## Requisito

Nenhum caminho de código DEVE produzir métrica, escore ou resultado a partir de geração
aleatória. A única aleatoriedade permitida é o reamostrador de bootstrap em
`evaluation/metrics.py`, que DEVE receber seed explícita.

## Justificativa

O v1 tinha 164 chamadas a `np.random` em `src/`, incluindo cross-validation sintetizada
em `medai_advanced_clinical_validation.py:357`.
