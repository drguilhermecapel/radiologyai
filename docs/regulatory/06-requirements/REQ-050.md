# REQ-050 — Avaliação reprodutível

## Requisito

Duas execuções de avaliação com a mesma seed e os mesmos dados DEVEM produzir resultados
idênticos. Todo artefato de avaliação DEVE registrar seed, versão do código, hash dos
pesos e hash do manifesto.

## Justificativa

Reprodutibilidade de uma execução de verificação é evidência exigida no arquivo de
histórico de projeto (IEC 62304 §5.7).
