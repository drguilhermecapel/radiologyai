# REQ-011 — Cobertura de des-identificação

## Requisito

A des-identificação DEVE remover ou pseudonimizar, no mínimo, os identificadores
diretos, UIDs de estudo/série/instância, dados institucionais, número de acesso e tags
privadas, conforme subconjunto do DICOM PS3.15 Annex E. UIDs pseudonimizados DEVEM
permanecer UIDs DICOM válidos (VR 'UI').

## Justificativa

O v1 cobria 7 tags e não tratava AccessionNumber, InstitutionName, UIDs nem tags
privadas.
