# REQ-102 — Achado de nível D só no modo pesquisa; nível vem do catálogo

## Requisito

O nível de evidência de cada achado DEVE vir de `radiologyai.catalog.Catalog` para o trio
(condição, modelo, rótulo); condição ausente do catálogo DEVE ser nível D com aviso. A
visibilidade DEVE ser derivada do nível: D é `research`, A-C é `main`. `AnalysisResult`
NÃO DEVE aceitar achado de nível D com visibilidade principal, e modelos zero-shot NÃO
DEVEM ser roteados para a visão principal.

## Justificativa

Um achado exploratório exibido ao lado de achados validados é lido como validado
(RISK-012). O nível precisa ser calculado da evidência, nunca digitado no adaptador.
