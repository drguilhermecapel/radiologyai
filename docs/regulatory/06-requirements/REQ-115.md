# REQ-115 — Registro medido com proveniência lida, não digitada

## Requisito

Todo registro medido DEVE carregar o sha do git lido do repositório, o `protocol_id`, o sha256 do manifesto do dataset calculado sobre todas as colunas exceto o escore (rótulo ausente distinto de negativo), o sha256 de cada arquivo de pesos calculado a partir do arquivo e o comando exato. A medição DEVE ser recusada com árvore git modificada salvo opção explícita, e nesse caso o registro DEVE trazer aviso de não reprodutibilidade. A sobrescrita do número de iterações do protocolo NÃO DEVE gravar na evidência do repositório. Os arquivos JSON gravados DEVEM satisfazer a regra R3 do `check_honesty.py` (hash de 64 hex na mesma linha da chave).

## Justificativa

Um registro sem como ser reproduzido é uma alegação. A cadeia sha do git → manifesto → pesos → comando é o que permite a um terceiro refazer a medição e obter os mesmos números.
