# REQ-118 — Estatística conferida contra valores de referência

## Requisito

As estatísticas do avaliador DEVEM reproduzir valores de referência: AUROC e AUPRC iguais a `sklearn.metrics.roc_auc_score` e `average_precision_score` (inclusive com empates), variância de DeLong igual à definição por componentes estruturais, ICC igual aos valores publicados por Shrout & Fleiss (1979) para as seis formas, Bland-Altman com DP amostral. Para concordância o protocolo DEVE usar ICC(2,1) (concordância absoluta); para comparação de dois modelos nas mesmas imagens, o bootstrap pareado por paciente é o método primário e DeLong é reportado com a suposição de independência declarada.

## Justificativa

Um erro na estatística produz número errado com aparência de medição. Conferir contra implementações e exemplos publicados é a verificação mínima.
