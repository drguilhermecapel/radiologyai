# REQ-142 — Código vendorizado do mammoscreen reproduz o original sem código remoto

## Requisito

Os adaptadores `mammo-crop` e `mammoscreen` NÃO DEVEM executar código remoto
(`trust_remote_code`) nem baixar nada fora do registro. As arquiteturas vendorizadas
(Apache-2.0, com `NOTICE` de atribuição e modificações) DEVEM carregar os safetensors
conferidos por sha256 com `load_state_dict(strict=True)` a partir dos mesmos bytes
verificados. O pré-processamento DEVE ser idêntico bit a bit ao do original
(`cv2.resize` INTER_LINEAR, pad de aspecto, `LongestMaxSize` + `PadIfNeeded` constante 0,
normalização `[-1, 1]`) e o ensemble DEVE fazer a média das probabilidades sobre as
incidências da mama e depois sobre as três redes. Sem OpenCV o adaptador DEVE levantar
`BackendUnavailableError` nomeando o extra, em vez de usar outra interpolação.

## Justificativa

Uma reimplementação "parecida" gera escores diferentes dos que o cartão descreve (perigo
H-04); executar código remoto contraria a política de cadeia de suprimentos.
