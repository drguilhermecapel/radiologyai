# REQ-114 — Vazamento treino/teste derivado de tabela explícita de linhagem

## Requisito

O campo `leakage` de um registro medido DEVE ser derivado de uma tabela explícita de chaves de dataset e da sua linhagem (ex.: SIIM-ACR e RSNA derivam do NIH), comparando a linhagem do dataset de avaliação com a linhagem das chaves de treino declaradas para o modelo. Chave de dataset desconhecida DEVE ser erro. O vazamento NÃO DEVE ser decidido por correspondência de substring em texto livre. Modelo sem dados de treino declarados DEVE resultar em `possible`.

## Justificativa

A checagem anterior por substring (`"nih" in nome`) classificaria SIIM-ACR — anotações sobre imagens do NIH — como externo para um modelo treinado no NIH, produzindo um falso nível A.
