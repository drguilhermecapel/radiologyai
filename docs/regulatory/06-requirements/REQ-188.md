# REQ-188 — Uso comercial "no" quando o treino inclui dados de termo não comercial

## Requisito

Todo manifesto de modelo cujo `training_data` inclui um dataset de termo não comercial ou restrito declarado em `radiologyai.evidence.leakage.NONCOMMERCIAL_TERMS` (CheXpert, CAMUS, MIMIC-CXR) DEVE declarar `license.commercial_use: 'no'`, nunca `unclear` ou `yes`.

## Justificativa

`xrv-ae-ood` (treino com CheXpert) e `medsam-vit-base` (treino com CAMUS, CC BY-NC-SA) estavam `unclear`, e os pesos só-MIMIC divergiam do CheXzero, também só-MIMIC e marcado `no`. A interface só mostra o aviso de pesos não comerciais para `no`.
