# REQ-160 — Plataforma serve exatamente o que o pipeline calculou

## Requisito

Toda resposta da API sobre uma análise DEVE vir do resultado imutável produzido por `radiologyai.analysis.pipeline.analyze` sobre as imagens ingeridas: modelos indisponíveis, planejados, não aplicáveis ou que falharam DEVEM aparecer com o motivo, e quando nenhum modelo pode rodar o resultado DEVE dizê-lo. A plataforma NÃO DEVE acrescentar, substituir ou recalcular escores, decisões ou níveis. A lista de trabalho DEVE mostrar o estado real da análise mais recente e da revisão.

## Justificativa

Regra de ouro (ROADMAP §7.3) aplicada à camada de plataforma: a API é onde o legado fabricava números.
