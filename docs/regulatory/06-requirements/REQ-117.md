# REQ-117 — Rótulo ausente nunca vira negativo; hash de manifesto cobre demografia

## Requisito

Na avaliação, imagem sem rótulo para um achado (ex.: CheXpert incerto ou não mencionado) DEVE ser excluída daquele achado e contada à parte, NÃO DEVE ser contada como negativa. O artefato de avaliação DEVE gravar, além do hash v1 (mantido para runs já commitados), o hash v2 do manifesto, que cobre todas as colunas, inclusive sexo, idade e incidência. A faixa etária DEVE separar menores de 18 anos.

## Justificativa

`Manifest.label_matrix()` devolve 0 para rótulo ausente, transformando "não sabemos" em "não tem" e inflando negativos; o hash v1 ignora demografia, então duas versões com subgrupos diferentes pareciam o mesmo dado.
