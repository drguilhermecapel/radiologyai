# REQ-164 — Respostas tipadas e contrato OpenAPI versionado igual ao gerado

## Requisito

Toda resposta JSON da API DEVE ter modelo pydantic declarado (congelado, `extra="forbid"`) e o contrato `docs/OPENAPI_SPEC.yaml` DEVE ser gerado pela própria aplicação (`radiologyai openapi`) e ser igual ao gerado a cada execução dos testes.

## Justificativa

Contrato documentado que diverge do código é como o OPENAPI do legado: promete o que o servidor não faz.
