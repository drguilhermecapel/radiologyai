# REQ-001 — Falhar alto na ausência de dependência

## Requisito

O sistema NÃO DEVE capturar `ImportError`/`ModuleNotFoundError` para desativar
subsistemas silenciosamente. Uma dependência ausente DEVE resultar em exceção explícita
que interrompa o processamento.

## Justificativa

O sistema v1 envolvia 37 imports em `except ImportError: self.x = None` e subia com
todos os subsistemas desativados, sem qualquer sinal ao usuário.
