# REQ-010 — Pseudo-identificadores determinísticos

## Requisito

Pseudo-identificadores de paciente DEVEM ser derivados por HMAC-SHA256 com chave
persistente, produzindo o mesmo valor entre execuções, processos e máquinas. O sistema
NÃO DEVE usar `hash()` builtin do Python.

## Justificativa

`hash()` é salgado por processo desde o Python 3.3. No v1, o mesmo paciente recebia
identificador diferente a cada execução, impedindo split estável.
