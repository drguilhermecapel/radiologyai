# REQ-132 — Achado derivado de volume só com regra pré-especificada e estrutura-alvo no campo

## Requisito

Todo achado derivado de volume segmentado (hemorragia, derrames, nódulo, cisto, lesão
hepática) DEVE usar um ponto de operação declarado no manifesto com origem: limiar publicado
(ex.: derrame pericárdico > 50 mL) ou regra de detecção pré-especificada do projeto (volume >=
0,1 mL), identificada como tal na origem. Tarefas de patologia DEVEM abster-se (motivo
`not_applicable_body_part`) quando o órgão-alvo, segundo o mapa anatômico a montante, não está
no campo de visão, em vez de relatar 0 mL.

## Justificativa

0 mL de hemorragia numa TC que não contém o encéfalo seria um falso negativo fabricado; um
limiar escolhido depois de ver os resultados inflaria o desempenho medido.
