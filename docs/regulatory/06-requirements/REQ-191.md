# REQ-191 — Significado dos níveis na interface espelha o catálogo e não diz "validado"

## Requisito

O texto PT-BR de `level.{a,b,c,d}.meaning` em `frontend/src/i18n/messages.ts` DEVE começar pelo
texto de `LEVEL_MEANING_PT` (`src/radiologyai/catalog/schema.py`) do mesmo nível. Nem esse texto,
nem sua versão em inglês, nem as tabelas de níveis de `README.md`, `ROADMAP.md` e
`docs/regulatory/01-intended-use.md` DEVEM usar "validado"/"validação" ("validated" em inglês).

## Justificativa

A interface descrevia o nível C como "validação interna nossa (mesma origem dos dados de
desenvolvimento)", mas entradas C podem vir de medição externa com sobreposição possível com o
treino ou de entrada derivada do padrão de referência. A palavra "validado" é linguagem vedada
pelo uso pretendido (§3.1) e induz leitura de validação que não ocorreu.
