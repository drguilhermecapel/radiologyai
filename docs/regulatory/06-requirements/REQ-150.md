# REQ-150 — Autenticação sem credencial padrão, senha argon2id e sessão opaca revogável

## Requisito

A plataforma DEVE autenticar por sessão opaca: token aleatório de 256 bits entregue uma única vez no login e guardado no banco SOMENTE como sha256, com expiração e revogação (logout, troca de senha, mudança de papel ou desativação revogam as sessões). Senhas DEVEM ser guardadas apenas como hash argon2id e obedecer a uma política mínima. A plataforma NÃO DEVE ter usuário ou senha padrão: o banco nasce vazio e o primeiro administrador é criado pela CLI (`radiologyai users create`). Falhas de login NÃO DEVEM revelar se o usuário existe e DEVEM ser limitadas por usuário.

## Justificativa

O legado guardava segredos de exemplo commitados e um banco de usuários no histórico (HONEST_STATUS.md). Credencial padrão e token reutilizável são as portas de entrada mais comuns de acesso indevido a dado de saúde (perigo de acesso não autorizado, RISK-020).
