# REQ-080 — API não fabrica métricas

## Requisito

Nenhum endpoint DEVE devolver métrica de desempenho que não venha de um artefato de
avaliação medido. Na ausência de artefato, a resposta DEVE declarar que não há medição,
em vez de devolver um número.

## Justificativa

medai_fastapi_server.py:340 criava y_true = np.array([1]) rotulado 'Mock ground truth',
calculava clinical_metrics a partir disso e devolvia ao cliente. A API informava a todo
chamador que o modelo fora clinicamente validado.
