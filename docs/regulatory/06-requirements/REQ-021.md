# REQ-021 — Saídas de modelo não treinadas não são reportadas

## Requisito

Quando um conjunto de pesos contiver cabeças de saída que não foram treinadas,
o sistema DEVE identificá-las, NÃO DEVE atribuir a elas o nome de um achado
clínico, e NÃO DEVE reportar métrica de desempenho para elas. Essas posições
DEVEM ser declaradas explicitamente entre os itens não avaliados, com o motivo.

## Justificativa

O torchxrayvision devolve string vazia em `model.pathologies` nas posições que o
dataset de treino não continha. Nos pesos `densenet121-res224-pc` (PadChest) são
os índices 14, 16 e 17 — correspondentes a `Lung Lesion`, `Lung Opacity` e
`Enlarged Cardiomediastinum` na lista default da biblioteca.

Usar `default_pathologies` como se fosse a lista do modelo faria o sistema
reportar AUROC de `Lung Lesion` a partir de uma cabeça nunca treinada: um número
que tem a forma de uma medição e não é uma. É a mesma classe de defeito que
produziu as métricas fabricadas do sistema v1, apenas por um mecanismo mais sutil.
