# REQ-183 — Réplicas de bootstrap indefinidas são contadas e reportadas

## Requisito

Toda estimativa com IC por bootstrap DEVE registrar quantas réplicas produziram estatística definida e quantas foram feitas (`n_defined_replicates`, `n_replicates`). Abaixo de 95% de réplicas definidas o IC DEVE ficar indefinido (o que reprova qualquer critério de limite inferior), e quem não reporta a contagem DEVE falhar com erro explícito. O registro de evidência DEVE declarar nos caveats as estimativas com réplicas indefinidas.

## Justificativa

Réplicas NaN eram descartadas em silêncio: o IC vinha de menos de B réplicas, enviesado para as definidas, enquanto o método declarava B=2000.
