# REQ-105 — Manifesto de modelo sem métricas, com códigos oficiais e licença declarada

## Requisito

O manifesto de modelo NÃO DEVE conter métricas de desempenho (accuracy, auc,
sensitivity, specificity e afins) em nenhuma profundidade. Todo rótulo DEVE ter código de
`pydicom.sr.codedict` com o significado oficial ou do esquema privado `99MEDAI`. O
adaptador DEVE ser uma classe sob `radiologyai.analysis.adapters.`. A licença DEVE
declarar código, pesos e uso comercial; código GPL/AGPL NÃO DEVE ser aceito. Modelo
disponível DEVE ter todos os pesos com sha256 fixado.

## Justificativa

Métrica no manifesto é alegação sem lastro (o defeito do `model_registry.json` legado).
Código clínico trocado rotula um achado com outra doença. Licença não declarada expõe o
responsável (RISK-014).
